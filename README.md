# Loft Quest

Gamification-App im Habbo-Hotel-Stil: Übe Skills, erledige tägliche Quests, verdiene Taler und richte damit dein isometrisches Pixel-Zimmer ein.

## Starten
`index.html` im Browser öffnen. Keine Installation nötig.

## Features
- Skills mit Level-System (1 Minute = 1 Taler, Level-up-Bonus)
- Tägliche Quests mit eigener Belohnung
- Tages-Serie mit Bonus
- Shop mit Möbeln, Deko, Böden und Tapeten
- Zimmer-Editor: platzieren, drehen, verschieben, einlagern, verkaufen

## Speichern
Lokal im Browser (localStorage). Als claude.ai Artifact zusätzlich im Konto über die `db`-Capability.
